# PC Frontier Lab

2015年に小さなPCハードウェア会社を設立し、CPU・GPUのシリーズを世代ごとに研究・開発・量産・販売する、TypeScript／Three.js製の経営シミュレーションです。

メイン画面は常時動く3Dオフィスです。時間は自動進行し、開発室、製品展示、工場管理、競合モニター、研究室、会議室から必要な経営画面を開きます。

## 現在の実装

- CPU／GPUシリーズと世代継承
- 研究・年代・技術資産・設備に連動する設計上限
- 6項目の設計から性能、効率、温度、原価、歩留まり、リスクを計算
- 対象市場を手動選択せず、性能・価格・効率・信頼性から購入層を自動判定
- 企画、詳細設計、テープアウト、試作、検証、量産承認の開発工程
- 工程ごとの追加費用、週次開発費、設計トラブルと対応判断
- 上位、標準、省電力、歩留まり活用の複数SKU
- 工場契約、立ち上げ期間、最低契約期間、予約料、週産上限、供給事故
- 在庫以上は販売できず、需要超過分は機会損失として記録
- 52～130週の製品寿命と自動終売、終売在庫の処分損
- 商品評価、週次需要、販売、在庫、市場シェア、利益、失速理由、推奨アクション
- Intel、AMD、NVIDIAの歴史的製品と、将来のゲーム内架空モデル
- 架空企業の参入、成長、資金難、買収、撤退
- 社員7職種、9専門分野、性格、成長、給与、疲労、士気、忠誠心、退職リスク
- 社員の専門分野が性能、歩留まり、電力、ドライバー、ブランド、工場交渉へ反映
- 研究費、給与、設備維持費、管理・知財・保険費、在庫費、サポート費、融資返済
- 設備投資、採用市場、研修、賞与、融資
- CPUパッケージ、GPU基板・ファン、ウェハ検査装置などを備えた3Dオフィス
- 自動セーブ

再設計の基準は [`REDESIGN_SPEC.md`](./REDESIGN_SPEC.md)、初期企画は [`GAME_DESIGN.md`](./GAME_DESIGN.md) にあります。

## 開発

```bash
npm install
npm run dev
```

型検査と本番ビルド:

```bash
npm run typecheck
npm run build
```

## Cloudflare Workers Static Assets

GitHub Actionsは使用しません。Cloudflare側で `bata-san/depy` を接続し、次を設定します。

- Production branch: `main`
- Root directory: `/`
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`

`wrangler.jsonc` はViteの出力先 `./dist` を配信し、未一致ルートを `index.html` に戻します。

## 市場データと商標

実在製品名は年代感と競争環境を表現するために使用しています。価格・性能・販売量はゲーム用の正規化値で、実測値や現在価格ではありません。信頼できる歴史的期間以降に生成されるIntel、AMD、NVIDIAのモデルは「ゲーム内架空モデル」と表示し、公式ロードマップとして扱いません。商標は各権利者に帰属し、本作との提携を示すものではありません。
