# PC Frontier Lab

2015年に小さな半導体会社を設立し、CPU・GPUシリーズの世代開発、量産、販売、研究、人材、資金繰りを行うTypeScript / Three.js製の経営シミュレーションです。

## 現在のゲームループ

- ボクセル調の3Dオフィスを常時表示し、HUDと右側の小型管理ドロワーから操作
- 3DカメラはUI再描画から独立し、ユーザーが動かした位置と注視点を保存
- 起動時セーブデータマネージャー、最大12スロット、自動保存、JSON入出力、名前変更、削除
- CPU・GPUのシリーズ作成と世代開発
- 対象市場は性能、価格、効率、品質から自動推定
- 標準速度は実時間約5時間でゲーム内1年、世代開発は約4分、研究は約1〜3分
- 技術上限、着手金、工程ごとの追加費用、試作、検証、マスク、ソフトウェア、設備、給与、管理費
- 標準で低価格・低品質の小規模工場と契約済み
- 複数工場の同時契約、製品別の生産割り当て、立ち上げ期間、最低契約、違約金、週産上限
- 上位、標準、省電力、歩留まり活用SKU
- 需要、生産、販売、在庫、機会損失、評価内訳、利益、売れた理由、失速理由、推奨行動
- 製品寿命による自動終売と発売後の価格、販促、更新、保証対応
- 職種、専門分野、特性、成長、給与、疲労、士気、忠誠心を持つ社員
- 設備投資、採用、研修、賞与、退職、複数の融資商品と週次返済
- Intel、AMD、NVIDIAの歴史的モデルと、非公式予測として明示した未来モデル
- 台頭、資金難、買収、撤退を行う架空企業
- 市場、競合、工場、社内の4経路だけに整理した低頻度の重要イベント
- タイピング、はんだ作業、検査、歩行、プレゼン、休憩を切り替えるボクセル社員
- CPUパッケージ、GPU基板・ファン、ウェハ検査装置、研究装置、サーバー、配送ロボのアニメーション

企画の基準は [`GAME_DESIGN.md`](./GAME_DESIGN.md)、現在の再設計要件は [`REDESIGN_SPEC.md`](./REDESIGN_SPEC.md) にあります。

## ローカル起動

```bash
npm install
npm run dev
```

型検査と本番ビルド:

```bash
npm run typecheck
npm run build
```

## Cloudflare Workers Static Assets

Cloudflare側のGit連携設定:

- Production branch: `main`
- Root directory: `/`
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Build output directory: `dist`

`wrangler.jsonc`は`./dist`を配信し、未一致のナビゲーションを`index.html`へ戻します。GitHub Actionsは使用しません。

## 市場データについて

実在企業・製品名は年代感と競争環境を表現するために使用しています。価格、性能、品質、需要はゲーム用の正規化値であり、実測値や実際のロードマップを示すものではありません。将来の実在企業モデル名はすべてゲーム内の架空・非公式予測です。商標は各権利者に帰属し、本作との提携を示すものではありません。
